# La terminal en 6 comandos

La terminal es una ventana donde das órdenes escribiendo, en lugar de hacer clic. Parece intimidante, pero
para tu proyecto usarás pocos comandos. Siempre estás "dentro" de una carpeta, y los comandos actúan sobre ella.

| Comando | Qué hace |
|---------|----------|
| `pwd` | Muestra en qué carpeta estás |
| `ls` | Lista lo que hay en la carpeta |
| `cd nombre` | Entra a la carpeta `nombre` |
| `cd ..` | Sube a la carpeta anterior |
| `mkdir nombre` | Crea una carpeta nueva |
| `code .` | Abre la carpeta actual en VS Code |

Estos comandos funcionan en la terminal de VS Code tanto en Windows (PowerShell) como en Mac y Linux.

Dos atajos que te ahorrarán mucho tiempo: la tecla **Tab** completa los nombres, y la flecha **↑** recupera
el último comando.

## Práctica

1. Abre la terminal y escribe `pwd` para ver dónde estás.
2. Crea una carpeta de trabajo con `mkdir mis-proyectos` y entra con `cd mis-proyectos`.
3. Crea la carpeta de tu primer proyecto: `mkdir tareas`, y entra con `cd tareas`.
4. Escribe `code .` para abrirla en VS Code.

Si `code .` no funciona, abre la carpeta desde VS Code con **File → Open Folder**.
