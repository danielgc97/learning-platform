# Tu primera función

Una función agrupa instrucciones bajo un nombre para poder reutilizarlas. Se define con `def`
y entrega su resultado con `return`.

```python
def doble(numero):
    return numero * 2
```

Si una función no tiene `return`, devuelve `None` (es decir, nada).

Ahora te toca a ti: resuelve el ejercicio de abajo.
