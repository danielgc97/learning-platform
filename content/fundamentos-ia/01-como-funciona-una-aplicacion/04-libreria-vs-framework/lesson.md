# Librería vs framework

Estas dos palabras se usan casi como sinónimos, pero describen cosas distintas. La diferencia está en
**quién tiene el control**.

## Librería: tú mandas

Una **librería** es un conjunto de herramientas que **tú llamas cuando las necesitas**. Tú decides cómo se
organiza tu proyecto.

- **React** es una librería para construir interfaces.
- **pandas** es una librería de Python para trabajar con datos.

## Framework: él manda

Un **framework** te impone una estructura y unas reglas, y es **él quien llama a tu código** en el momento que
corresponde. Tú rellenas las piezas que te pide.

- **FastAPI** es un framework para construir backends en Python: tú defines funciones y él las ejecuta cuando
  llega una petición.
- **Next.js** es un framework construido sobre React.

## En la práctica

En conversaciones cotidianas verás que la gente llama "framework" a todo. No pasa nada, pero la pregunta útil es:
**¿quién controla el flujo, mi código o la herramienta?** Si controlas tú, es una librería; si te guía ella,
es un framework.
